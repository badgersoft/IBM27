# Notes for working on this project

* Versioning: while the game is a prototype, every build (each change pushed
  for the client) bumps the last number of `application/config/version` in
  `project.godot` (0.1.1 -> 0.1.2 -> ...), with an entry in `CHANGELOG.md`.
* Keep the UI tidy: 1280 x 800 frame, 8 px grid, font sizes 8/16/24/32/48,
  right-aligned numbers, no misaligned columns.
